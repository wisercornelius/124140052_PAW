Formulir Pendaftaran

Halaman pendaftaran menggunakan form dengan method GET. Data dikirim melalui query string menuju halaman detail pendaftar.

Data Pendaftar

Lengkapi seluruh data di bawah ini dengan benar.

Rancangan query string. Karena form memakai method="GET", data akan dikirim ke halaman detail dalam bentuk pasangan name=value yang dipisahkan tanda &. Halaman detail hanya menampilkan data dummy (query string tidak ditangkap/diproses):
detail.html?nama=...&nim=...&kelas=...&prodi=...&email=...&telepon=...&jenis_kelamin=...&tanggal_lahir=...&alamat=...
